# Diferenças entre cores na vida real e na computação
**18/08/2026**

## Introdução

As cores fazem parte do nosso cotidiano, mas a maneira como enxergamos uma cor na vida real é diferente da forma como um computador representa essa mesma informação.

Na computação visual, as cores precisam ser transformadas em valores numéricos para que possam ser armazenadas, processadas e exibidas em uma tela.

## Como enxergamos as cores na vida real 

Na vida real, nossa percepção das cores está diretamente relacionado á luz. Quando a luz atinge um objeto, parte dela é absorvida e outra é refletida.

A luz refletida chega aos nossos olhos e nosso cérebro interpreta essa informação como uma determinada cor.

## Como o computador representa as cores

Uma das formas mais utilizadas para representar cores é o modelo RGB.

RGB que significa:

- Red ( Vermelho )
- Green ( Verde )
- Blue ( Azul )

  Cada uma dessas cores normalmente recebe um valor entre 0 e 255.

  Exemplos:

  - RGB( 255, 0, 0) = Vermelho
  - RGB( 0, 255, 0 ) = Verde
  - RGB( 0, 0, 255) = Azul
  - RGB( 255, 255, 255) = Branco
  - RGB( 0, 0, 0) = Preto

## RGB e mistura de luz

As telas utilizam luz para produzir as cores. Por isso, o modelo o RGB funciona através de mistura.

Quando vermelho, verde e azul estão em sua intensidade máxima obtemos a cor branca.

## Por que uma cor muda de uma tela para outra?

Mesmo utilizando os mesmos valores RGB, uma cor pode parecer diferente dependendo do dispositivo.

Alguns fatores que podem causar essa diferença são:

- brilho
- contraste
- tecnologia da tela
- calibração
- iluminação do ambiente
- espaço de cores utilizado

## Conclusão

Embora utilizemos os mesmos nomes para falar sobre cores na vida real e no computador, os dois casos funcionam de formas diferentes.

Na vida real, nossa percepção depende da luz, dos objetos, do ambiente e do funcionamento dos nossos olhos e cérebro.

Já na computação, as cores precisam ser representadas matematicamente por valores numéricos.

Entender essas diferenças é importante na Computação Visual, pois permite compreender melhor como imagens são criadas, armazenadas, processadas e exibidas digitalmente.
